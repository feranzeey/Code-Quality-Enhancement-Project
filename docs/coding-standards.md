# Team Coding Standards

## Naming Conventions

### Files

* Use lowercase names.
* Use hyphens or underscores consistently.

Examples:

* deployment_config.py
* quality-check.sh

### Variables

* Use descriptive names.
* Use snake_case.

Example:

* user_name
* deployment_status

### Constants

Use UPPER_CASE.

Example:

* MAX_RETRIES

## Documentation

* All projects must contain a README.md.
* Complex logic must be documented.
* Configuration files must include comments where appropriate.

## Security

* Never hardcode passwords.
* Use environment variables for secrets.
* Review dependencies regularly.

## Git Workflow

* Create feature branches.
* Use meaningful commit messages.
* Submit pull requests for review.
